# Kezhou Lu academic homepage

This folder contains a simple GitHub Pages-ready homepage for Kezhou Lu, adapted from the content in the CV PDF.

## Publish on GitHub Pages
1. Create a GitHub repository and upload this folder.
2. In the repository settings, enable GitHub Pages.
3. Choose the root folder (or the main branch) as the publishing source.
4. Open the generated URL to view the site.

The page uses the existing CV PDF as a downloadable file.
